# Tests
## What are Tests?
Tests are the perfect opportunity for developers to create public overviews of features and components. These can be reused over time.

## What types of Tests are there?
There are 2 Types:
1. The Full Type
It is a single page with every component.
   
2. The Personal Type
Every developer can use a template an create their own Test page.
